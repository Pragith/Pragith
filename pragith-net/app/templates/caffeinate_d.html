Caffeinate-d

A macOS menu-bar app that keeps your display awake using caffeinate -d.

Get the source code

Scope

Caffeinate-d starts and stops caffeinate -d from the menu bar to keep your display awake.

Release state: Source version 0.2.0. Build it in Xcode; a matching packaged release or signed app download is not available.

Install
Build the application from source with Xcode. See the steps below.

Privacy

The published source runs a local macOS command. It requires no account or remote service.

Build from source

  1. Clone the repository on macOS.
  2. Open its Xcode project.
  3. Build the application.
  4. Run the application.
  5. Use the menu-bar toggle to keep your display awake.
