Sample exercise: check a CSV before reporting

For learners who can write Python functions and iterate over CSV rows. This self-contained example uses six fictional orders.

Write a check that separates valid orders from duplicate IDs, missing amounts and non-positive amounts. Report rejected row numbers and calculate the total from accepted rows.

Download the datasetReference solutionExpected output
python3 check_orders.py orders.csv
Assessment criteria for this exercise
CheckObservable result
ValidationReject the duplicate, negative amount and empty amount with row numbers.
AggregationAccept 3 orders; total 56.25.
RepeatabilityRunning the same input twice produces the same output.
ExplanationExplain why a rejected amount stays outside the total.
